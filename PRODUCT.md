# Product

## Register

product

## Platform

web

## Users

development teams and engineering leads who want automated code review assistance

## Product Purpose

Catch issues before human review so engineers focus on architecture, not style

## Brand Personality

thorough, technical, dependable

## Anti-references

- Generic SaaS templates with purple-to-blue gradients
- Over-designed dashboards where data is buried in decoration
- AI-generated interfaces that all share one look (Inter font, cream backgrounds, rounded everything)
- Enterprise apps that confuse density with professionalism

## Design Principles

- Multi-agent means multiple perspectives on the same code
- Categorize findings by severity: block, warn, inform
- Never block a PR on style — only on correctness and security
- Reviews should teach, not just flag

## Accessibility & Inclusion

- WCAG 2.1 Level AA compliance target
- Proper color contrast ratios (body text >= 4.5:1, large text >= 3:1)
- Keyboard navigable interface
- Screen reader friendly semantic HTML
- Support for prefers-reduced-motion and prefers-color-scheme
